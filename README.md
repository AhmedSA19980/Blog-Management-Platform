# Django Blog Management System

A web-based blog management application built with **Python and Django** that provides user authentication and basic blog content management functionality.

## Features

* User registration and authentication
* Secure user login and logout
* Create new blog posts
* Update existing blog posts
* User-based post management
* SQLite database integration
* Django-based server-side application architecture

## Technologies

* **Python**
* **Django**
* **SQLite**
* **HTML / CSS**
* **Django Templates**

## Project Purpose

This project was developed to practice building a database-driven web application with Django. It demonstrates fundamental concepts including authentication, user registration, CRUD operations, database persistence, URL routing, views, models, and Django's template system.

## Key Learning Outcomes

* Understanding Django's project and application structure
* Working with Django models and the ORM
* Implementing user authentication and registration
* Building CRUD functionality
* Connecting a Django application to a relational database
* Handling requests, views, templates, and URL routing
